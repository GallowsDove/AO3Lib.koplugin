Original masks, default CSS colors and Git blob SHAs are in this repository's
assets/ao3-icons-zerafina/source/ directory.

tools/build_zerafina_icons.py composites those masks with the default CSS
backgrounds and borders. Empty squares and the colored Multi quadrants follow
the CSS. The E-reader variant uses the same conversion as ao3-icons-eink,
including its flat backgrounds, ordered rating tones and four gray quadrants.
Antialiasing is retained. No external resources are loaded at runtime.
